_Date: 2026-07-24 · Ticket: **PIA-030** · Author: A1 (Inventory/Explorer) · Sources: `pialax.html` (4,986 lines), `pialax-mobile.html` (5,133 lines), `index.html`, `PIALAX-PROJECT-DEFINITION.txt`, `SPRINT_PROPOSAL_2026-07-21.md`, `CLAUDE.md`_

This document is the **zero-feature-loss contract** for the UI overhaul (PLAN_UI_OVERHAUL_2026-07-24.md). Every feature row below was observed in the shipped code and MUST survive the overhaul byte-for-behavior: a diff that removes, hides, or degrades any row is a NO-GO regardless of visual quality. Rows record anchors (functions / element IDs / constants with approximate line numbers, format `pialax.html:~NNNN / pialax-mobile.html:~NNNN`), observable behaviors including edge cases, and desktop/mobile divergence. The Persistence contract (§P) and Security/infra surface (§S) are FROZEN. No redesign opinions appear in this file.

Line-number convention: mobile mirrors desktop logic at an offset of roughly +450 to +560 lines; anchors below give both. "identical" in the divergence column means logic + IDs + observable behavior match (styling naturally differs between the two files).

## 1. App entry / redirect (`index.html`)

- **Device-detect redirect shim** — Where: `index.html` (whole file). Anchors: inline IIFE using `navigator.userAgent` regex + `matchMedia('(pointer:coarse)')` + `max-width:820px` + `ontouchstart`; `location.replace()`. Behaviors: forwards to `pialax-mobile.html` or `pialax.html` **carrying the full query string AND hash** so share links survive the hop; `location.replace` keeps the shim out of back-button history; on JS exception falls back to `pialax.html`; `<noscript>` meta-refresh fallback to desktop; visible fallback UI (spinner `.spin`, "Opening your flight dashboard…", manual Desktop/Mobile links); light-mode support via `@media (prefers-color-scheme:light)`.
